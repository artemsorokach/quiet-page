# Quiet Page

A quiet, private space for self-reflection: free writing, gentle questions, mood and feelings,
and a path of entries over time. Entries are encrypted on the device; only their owner can read them.

Live: https://artemsorokach.github.io/quiet-page/

- `main` serves the current site (`index.html` at the root).
- `v2` is the component-based rewrite (Vite + TypeScript + Preact). The old site lives in `legacy/` there.

Development notes, data formats and principles: [CLAUDE.md](CLAUDE.md). Decisions: [docs/adr](docs/adr/README.md).
